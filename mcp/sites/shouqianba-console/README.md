# 收钱吧本地经营台与 MCP

安装、启动和客户端配置见 [连接器总说明](../../README.md)。需要 Windows 和 Node.js 24.5+；服务不依赖第三方 npm 库。

在 `mcp` 目录执行 `Start-Shouqianba.ps1`，访问 `http://127.0.0.1:8788/`，手动完成人机验证、短信登录和商户身份选择。用 `Stop-Shouqianba.ps1` 停止由该脚本启动的进程。

`mcp-stdio.mjs` 将 MCP 请求转到本机 HTTP 服务，并读取运行后生成的本地密钥。先启动网页服务，再连接 MCP。18 个只读工具覆盖门店、营业、交易、退款查询、支付详情、商品、销量、库存汇总、订单毛利、顾客和储值信息。先调用 `sqb_status`；金额及数据覆盖范围以响应为准。储值充值本金与消费核销分开统计，游标查询应继续到末页，订单毛利不能当作净利润。

会话由 Windows DPAPI 加密，存于 `mcp/.local/shouqianba/`。浏览器和 MCP 使用独立本地密钥，不返回登录令牌。短信及登录仅通过网页完成，MCP 不开放支付、退款、充值、核销或数据修改。

`lib/analysis.mjs`、`lib/store-change.mjs` 和分析页保留通用计算与展示代码，仓库不带任何商户数据、报告或原始顾客清单。没有当前商户报告时分析页会返回未就绪状态。

在本目录运行 `npm test`。测试使用模拟云端响应及临时目录，不连接真实商户。
