# 海康云台观察与调测技巧

根据用户提供的 `haik-camera-survey/SKILL.md` 及 `scripts/camera.mjs` 整理，来源记录日期为 2026-10-17。下列设备经验是当时的观察，不保证账号、安装方向、网络或固件改变后仍相同。当前设备 ID、权限及在线状态以 `list_cameras` 和实际工具结果为准。阅读这份参考不构成移动摄像头的请求。

## 先看画面，再判断云台

1. 先选定真实 cameraId，按 1 fps 采集约 6 秒，读取并查看保存的原图。`online`、HTTP 成功、解码成功都不能代替这一步。画面无效时不继续环绕。
2. 看见“405 信令传输超时”等文字卡片，应报告视频链路故障。该卡片曾为 512×288，但分辨率本身只能作提示，不能证明卡片或正常场景。辅助脚本遇到这个尺寸会保守中止并给出原始任务，供人工/图片工具核查。
3. 默认 `quality: 2`。用户资料记录质量 1 在这批 4G 设备上可能返回 `20001` 或空流；需要细节时可以尝试质量 1，失败后说明并使用质量 2。不要将所有 `20001` 都归因于清晰度，也不要据此猜通道号。
4. `Video: none` 或 codec ID 12 报错可能是旧式 HEVC FLV 封装。内置采集服务已做容器标准化；使用它，不必再次写解码器或改变摄像头编码、加密设置。

## 停止后给视频延迟留时间

4G 视频有缓冲。停止刚确认时抓到的帧可能仍是移动前画面，不能立即判定电机失灵。对这批设备可先在停止后等待约 **4 秒**，然后取得新样本；这是经验起点，结合画面中的时钟和连续帧判断，不是延迟上限或所有设备的固定值。脚本默认 `--settle 4`。

同方向数次短移动后画面不变，可能是限位、遮挡、单步角度小、取帧滞后或环境纹理少。先确认停止、等缓冲、检查新帧。若当前用户请求包含云台调测/环绕，可在停止已确认后用一次有界的反方向移动检查限位；不要自动长距离反转，或用反向动作抵消不确定的移动。普通静态观察不包含移动授权。

默认从 300 ms、速度 2 开始，保持单摄像头串行。用户资料的单步约 1–3° 是特定设备经验，时间不是角度反馈。短批次先做约 12 步，必要时才增加，辅助脚本每次最多 40 步；不能为了“确保转完”悄悄追加上百步。将网络、停止、4 秒等待和采集时间算入进度，勿承诺固定每步 1.5 秒。

## 用图像差异辅助复核

保留原图；需要倒转查看时只生成旋转副本，先确认实际安装方向。用户资料记录两台设备曾倒装，不能对所有新帧默认旋转 180°。烧录在画面内的 OSD 在旋转副本中也会跟着倒转，这不是镜像处理。

脚本用 64×36 灰度缩略图，统计像素差值大于 8/255 的占比 `diffPct`，分别比较前一采样与开场采样。它比单一余弦相似度更便于发现变化，但光照、人员移动、遮挡和均匀墙面都会影响结果。先有明显偏离，再出现较低开场差异（例如低于 12%），也只表示**画面相似的候选**；必须查看原图，不证明回到精确角度，更不证明覆盖完整 360°。`closestToOpening` 是最相近的已采样帧，不是自动归位功能。

## 错误处理

| 现象/代码 | 建议 |
| --- | --- |
| `20008`、移动超时 | 不重放动作。确认真实最近方向的停止，检查延迟后的帧，再决定是否继续用户授权的任务。脚本会结束本批次，保留报告。 |
| `20032` | 服务已对明确通道拒绝刷新授权并重试一次；报告持续错误，不循环、不猜 ID 或通道。 |
| `50000` | 该次操作失败；不能算成功步骤。确认停止并取新帧后，才考虑下一批，勿立即重放。 |
| `60000` | 该设备/该方向可能不支持。用户资料记录这两台设备变焦不支持，不代表所有摄像头均如此。 |
| `PTZ_STOP_REQUIRED` / `PTZ_STOP_UNCONFIRMED` | 优先停止，使用真实最近方向。服务端已有有限重试；辅助脚本最多补一次。仍失败则停止后续移动，告知用户检查原 App。 |
| 服务在移动期间重启或断开 | 原进程的移动历史可能丢失。恢复后，对所有停止仍不确定的已操作摄像头，按各自真实最近方向显式停止并确认；不要用重启绕过停止保护。 |

## 可复用辅助脚本

[scripts/camera-survey.mjs](../scripts/camera-survey.mjs) 根据所给脚本改编，复用现有 `camera_capture_start`、`capture_status`、`move_camera`、`stop_camera`。不访问凭据文件、不获取或保存云端签名地址、不运行旧云连接器，不会因阅读技能而自动执行。`status` 只读；`probe` 会保存有限时长图片；`survey` 只用于用户已请求的调测/环绕。

从工作区根目录运行；其它目录或已安装插件中运行时，先设置 `HAIK_ROOT` 为实际工作区。需要该工作区已有的 `tools` 中 `sharp`，以及已启动的本地 8787 服务；端口可由 `HAIK_PORT` 指定。

```powershell
$env:HAIK_ROOT = 'C:\McpConnectors'
$survey = Join-Path $env:HAIK_ROOT 'sites\haik-console\skills\haik-camera\scripts\camera-survey.mjs'
node $survey status
node $survey probe '<list_cameras 返回的 ID>' 6
```

先用本机图片工具查看 probe 返回的原图。确认是有效场景后，在当前移动授权范围内调用：

```powershell
node $survey survey '<选定 ID>' --probe-job '<刚检查的任务 ID>' --steps 12 --dir right --every 2 --settle 4 --label survey
```

脚本只接受该摄像头最近 5 分钟内完成的实时 probe 任务；它不能代替调用方检查实际画面。`--every 2` 表示预先授权的同方向短批次每 2 步采样，单步排障用 `--every 1`。移动或采样失败时结束本批次；停止未确认时不再移动。`--rotate 180` 仅在原图已确认倒装时使用；默认不旋转。脚本不会自动反向、重放失败动作或宣称归位。

原始任务继续保存在 `.local/haik-captures/<job-id>/`；脚本另写 `.local/camera-surveys/<label>-<timestamp>/report.json`、`view_*.jpg` 查看副本及 `sheet.png`。报告关联原始路径、任务 ID、序号、近似采集时间和 SHA256。可离线重建拼图：

```powershell
node $survey sheet '<报告目录>' 5
```

只支持 MCP 工具/资源的客户端可以调用 `camera_usage_guide {"section":"survey"}` 阅读本参考，或 `{"section":"survey-script"}` 取得完整脚本文本并保存到受控的本地路径运行；仅返回文本不会自动安装或执行脚本。拥有插件文件的客户端可直接使用随包脚本。

## 当前设备经验与结果表述

用户资料曾记录 `EXAMPLE_CAMERA_01:1`、`EXAMPLE_CAMERA_02:1` 使用 H.265、768×432 子码流和约 2 fps 源帧率，具有 4G 视频延迟；第二台水平与垂直移动可用，但长时间向右后会到限位。所有这些都须在当前设备列表中核实后应用；不能用本次文档更新声称重新测过设备。

报告实际采样区间、成功/失败步骤、停止确认、已查看的视角和证据位置。无角度反馈时，不能承诺一圈或精确回原位。若需要巡航/预置位能力，目前 MCP 未提供；可说明由用户在原 App 配置后再观察，不自动新增巡航、修改设备配置或用大量短步假装完成。
