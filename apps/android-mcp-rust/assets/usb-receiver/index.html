USB 备用下载

Wi-Fi 下载不方便时，用数据线接收电脑安装包。

返回下载首页
第 1 步 / 共 3 步准备 → 接收 → 保存

保存接收页并打开

保存接收页在浏览器下载列表中找到它，用电脑 Chrome 或 Edge 打开。

打开保存的页面后，点击“下一步”。

连接设备并接收

用 USB 数据线连接电脑与设备，再选择设备开始接收。

尚未开始

找不到设备时，请检查数据线，并关闭正在连接设备的其他软件。

保存安装包并解压

  1. 在浏览器下载列表中找到“设备操作台.zip”。
  2. 右键选择“全部解压缩”。
  3. 打开解压后的文件夹，双击“设备操作台”。

保存后还需自行解压、打开程序。

请先准备接收页。

校验详情

每块 CRC32 检查，完整 SHA-256 一致后才允许保存。
