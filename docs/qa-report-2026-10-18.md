## 兼容性与未关闭事项

- **MCP 接入变化**：原来未声明只读的工具现在需要授权；页面直调的 MCP 服务应补充准确的 `readOnlyHint: true`。不能用该注解掩盖写入行为。
- **页面地址变化**：对外 `PageView.url` 保持兼容，首次进入后跳转到带页面令牌的资源目录。页面地址本身携带访问权限；页面响应禁止发送 referrer。iframe 和 bridge 集成应使用已更新的 opaque 规则。
- **依赖审计仍有 3 条 moderate 告警**，高危和严重告警均为 0。这 3 条来自同一 `mammoth → argparse → sprintf-js` 链，审计编号为 `GHSA-hp3w-g68c-fv3c`。审计建议降级到 Mammoth 0.3.29，本轮未作这种会影响 DOCX 能力的降级。当前使用的 `mammoth.browser.js` 不包含 argparse/sprintf-js，但依赖树告警尚未关闭。默认 npm 镜像不提供审计接口，本结果使用官方 npm registry 取得。
- **外部服务与实机**：真实模型的生成质量、生产 ERP、飞书、短信/相机账号及真实设备不在离线模拟结果的保证范围内。本轮没有发送真实消息、短信，或操作、烧录真实设备。
