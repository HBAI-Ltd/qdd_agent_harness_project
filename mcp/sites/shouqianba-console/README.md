# 收钱吧本地经营台与 MCP

安装、启动和客户端配置见[连接器总说明](../../README.md)。需要 Windows 10/11、Node.js 24.5+；本服务只依赖 Node.js 内置模块。

## App 原生登录配置

仓库不带账号、令牌、厂商客户端认证参数、设备指纹或本机密钥。使用自己合法取得且适配当前 App 协议的客户端参数初始化。在仓库的 `mcp` 目录执行：

```powershell
New-Item -ItemType Directory -Force .local
Copy-Item shouqianba-client-config.example.json .local/shouqianba-client-config.json
# 本机编辑JSON，填写appId、appSecret和对应version；不要提交此文件
node scripts/initialize-shouqianba.mjs
.\Start-Shouqianba.ps1
```

初始化在 `.local/shouqianba/native-profile.dpapi` 加密保存配置，独立生成并持久化随机设备标识，标注为 Windows 本地桥，不冒充安卓硬件或可信设备。已有配置不会被初始化器覆盖，重复执行不会更换设备标识，也不发送短信或访问云端。初始化后可自行删除含明文参数的本地输入JSON；加密配置仍保留。自定义状态目录使用 `SQB_STATE_DIR`；初始化器与服务需使用同一目录。`SQB_CLIENT_CONFIG_PATH` 可指定另一份本地输入文件。

启动后访问 `http://127.0.0.1:8788/`，自行完成人机验证、短信登录和普通商户身份选择。配置加载成功时页面显示 App 登录方式；未初始化则沿用网页鉴权，不能将网页令牌说成App会话。需要已有设备确认或额外验证时明确提示，不跳过服务端风控。集团/品牌的原生身份切换尚未启用。使用 `Stop-Shouqianba.ps1` 停止有进程记录的服务；它保留当前Windows用户的加密会话。

## 会话恢复与维护

App 原生鉴权实现固定生产域名、端点白名单、设备/公共参数和请求签名；不提交生产 AppSecret。原生刷新接口为 `GET /v5/ucToken/refreshToken`，`threshold=86400`沿用App默认值，不据此推定租约单位或期限。正常TLS校验不变，错误不返回原始凭据。

服务启动后自动尝试恢复App会话，运行期间每6小时刷新并检查账户，关闭网页仍执行。网络、超时、未知响应或保存失败时保留凭据，按1/5/15/60分钟退避，之后每6小时重试；明确不可继续的登录状态需要重新验证。并发请求共享令牌刷新，断开后迟到响应不能恢复旧账号。后台维护不是永久有效保证，真实续租应以返回的 `expire_time` 是否延后为准。

网页和 `sqb_status` 显示当前服务端到期时间、最近检查及后台重试状态。脱敏历史 `.local/shouqianba/keepalive-history.json` 最多120条，只含时间、成功/错误码、到期时间及令牌是否变化的布尔值。电脑关机或服务停止时不发维护请求，下次启动再恢复。不会注册开机自启。

## MCP 和经营数据

`mcp-stdio.mjs` 转发到本机 HTTP 服务，并读取本机生成的访问密钥；先启动经营台再连接MCP。配置见 `mcp/mcp.client.example.json`，把stdio入口改为安装目录中的实际绝对路径。HTTP `/mcp` 要求独立Bearer密钥，登录网页及浏览器API限制为回环Host/Origin。默认仅监听127.0.0.1；外部访问应另行配置，不能将匿名HTTP示例套到本服务。

18个只读工具覆盖门店、营业、交易、退款查询、支付详情、商品档案/销量、库存汇总、订单毛利、顾客、储值方案/账户/余额/账单及详情。先调用 `sqb_status`；具体金额和覆盖范围以响应为准。充值与消费分开统计，游标继续翻到末页，订单毛利不是净利润。MCP不发送短信，也不开放收款、退款、充值、核销、改价或删除操作。

App令牌被某个经营数据服务拒绝时，重新检查原生账户；原生会话仍有效则返回 `DATA_AUTH_UNVERIFIED` 并保留凭据，不能把服务间授权不兼容当作原生令牌撤销。

`lib/analysis.mjs`、`lib/store-change.mjs`及分析页保留计算和展示代码；仓库没有商户报告、顾客清单、定位资料、监控截图或APK分析资产。无当前商户报告时分析页显示未就绪。

## 验证

在本目录运行 `npm test`。包含真实本地HTTP/stdio、Windows DPAPI和子进程重启验证，以及模拟上游的签名、短信回调、启动恢复、定期维护、断网退避、并发、保存失败、撤销和用户主动断开测试。测试不访问真实账号、不发短信，也不改变真实运行服务的凭据。凭据初始化测试验证新安装独立设备标识、加密保存、缺参数时拒绝初始化以及已有配置不被覆盖。

`.local/`、`*.dpapi`、本地密钥及非example配置已被Git忽略。复制源码到另一台机器时，需要重新初始化和登录；不要复制运行后的私有目录。
