name: cameras
description: 使用本地天翼视联服务查看本人授权摄像头、实时画面、云/SD录像、截图和持久化采集任务，以及用户明确要求的短时云台操作。用户提到天翼视联、移动摄像头或本插件时使用。
---

通过本插件提供的 `tysl_camera_*` 和 `tysl_capture_*` 工具处理天翼视联摄像头请求。

先调用 `tysl_camera_status` 检查服务和登录状态。服务连接失败时说明本地控制台尚未启动；未登录时引导用户打开本机 http://127.0.0.1:8790 完成官方登录。不要索要或读取账号令牌、密码、验证码、DPAPI 文件或浏览器凭据。

用 `tysl_camera_list` 获取设备并使用返回的真实 cameraId。只有设备名称匹配不唯一时，才让用户选择设备；不要凭空编造 ID。

用户要查看画面时调用 `tysl_camera_preview`，使用返回的本地网页/视频地址。用户要历史录像时，先查云录像日期或按北京时间日期调用 `tysl_camera_recordings`；明确 cloud 与 sd 来源，按工具分页读取。云录像通过已查询的 recordId 与 date 调用回放。SD 录像使用已查询片段或用户指定起止时间。能力支持不代表设备一定存有录像，空列表也不代表整个历史没有录像。

截图使用 `tysl_camera_snapshot`。持续保存图片或视频使用 `tysl_camera_capture_start`，按用户指定时长和采样频率提交；通过 `tysl_capture_status` 分页获取进度和已保存文件。仅在实际工具返回完成及文件路径后，才说明文件已保存。可以用可用的本地图片读取工具继续分析返回图片；不要把文件上传至外部站点。

仅在用户明确要求移动云台时调用 `tysl_camera_ptz`，采用有界短脉冲；用户要求停止时立即调用 `tysl_camera_stop`。取消采集使用 `tysl_capture_cancel`，说明已生成文件仍保留。

本插件只连接本机 8790 服务。依据工具的真实错误报告失败，不使用别的摄像头服务替代，不向用户输出云端签名地址或任何认证材料，不修改摄像头编码、存储、告警或网络配置。
